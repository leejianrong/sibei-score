# Third-party notices — @sibei/engrave

## Bravura

`src/bravura.generated.ts` contains a slice of the **Bravura** music font: the
`engravingDefaults` table, and the metrics and outlines of fifteen glyphs. It is
generated by `scripts/vendor-bravura.ts` from the `bravura-1.392` release and is not
edited by hand.

- Copyright © Steinberg Media Technologies GmbH
- Licensed under the **SIL Open Font License, Version 1.1**
- <https://github.com/steinbergmedia/bravura>, `redist/OFL.txt`

The OFL permits redistribution of the font and of derivatives. The glyph outlines here
are verbatim path data from Bravura's own SVG font, and the metrics are verbatim values
from `bravura_metadata.json`; nothing is modified. The generated file carries no
Reserved Font Name and is not itself distributed as a font.

ADR-0027's dependency register already lists Bravura under SIL OFL, as the font VexFlow
draws with. This package reads the same font's published metrics directly instead of
through VexFlow, which is what ADR-0030 asks for.

## SMuFL glyph names

`scripts/vendor-bravura.ts` reads SMuFL's `glyphnames.json` at vendoring time to
resolve glyph names to codepoints, so that no codepoint is transcribed by hand. That
file is **not** redistributed here — only the codepoints it resolved, which are facts
about the SMuFL specification rather than a copyable work.

- <https://github.com/w3c/smufl>, `metadata/glyphnames.json`
